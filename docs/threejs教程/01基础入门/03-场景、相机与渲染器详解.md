## 场景 (Scene)

### 基本创建

```javascript
const scene = new THREE.Scene();

// 设置背景色（支持颜色值、纹理、环境贴图）
scene.background = new THREE.Color(0x1a1a2e);

// 设置雾效（远处的物体会逐渐模糊消失）
scene.fog = new THREE.Fog(0x1a1a2e, 10, 100);
```

### 场景层级结构

```
Scene
├── Object3D (Group)
│   ├── Mesh (立方体)
│   ├── Mesh (球体)
│   └── Group
│       ├── Mesh (圆柱体)
│       └── Mesh (圆环)
├── Mesh (平面)
└── Lights
    ├── DirectionalLight
    ├── AmbientLight
    └── PointLight
```

### 对象添加与移除

```javascript
// 添加到场景
scene.add(mesh);

// 一次性添加多个
scene.add(mesh1, mesh2, mesh3);

// 从场景移除
scene.remove(mesh);

// 隐藏/显示（不影响渲染性能）
mesh.visible = false;

// 递归操作（对组内所有子对象生效）
group.traverse((child) => {
    if (child instanceof THREE.Mesh) {
        child.material.visible = false;
    }
});
```

### 获取场景中的对象

```javascript
// 按名称获取（需要先设置 name 属性）
const mesh = scene.getObjectByName('myCube');
mesh.name = 'myCube';

// 按类型获取所有对象
const meshes = [];
scene.traverse((child) => {
    if (child instanceof THREE.Mesh) {
        meshes.push(child);
    }
});

// 获取所有光源
const lights = [];
scene.traverse((child) => {
    if (child instanceof THREE.Light) {
        lights.push(child);
    }
});

// 获取场景中的所有对象
const allObjects = scene.children;
```

### 场景信息查询

```javascript
// 判断对象是否在场景中
const isInScene = scene.children.includes(mesh);

// 获取对象在场景中的索引
const index = scene.children.indexOf(mesh);

// 获取对象数量
const count = scene.children.length;
```

### 场景工具方法

```javascript
// 销毁场景中的所有对象
scene.dispose();

// 递归遍历并执行回调
scene.traverse((object) => {
    console.log(object.type, object.name);
});

// 复制对象（深拷贝）
const clonedMesh = mesh.clone();
scene.add(clonedMesh);
```

### 环境相关

```javascript
// 设置环境贴图（用于反射效果）
scene.environment = environmentMap;

// 设置场景矩阵（通常自动计算）
scene.matrixAutoUpdate = true;

// 更新场景中所有对象的矩阵
scene.updateMatrixWorld();
```

## 相机 (Camera)

### 相机类型对比

| 类型 | 类名 | 特点 | 适用场景 |
|------|------|------|----------|
| 透视相机 | PerspectiveCamera | 近大远小，符合人眼视觉 | 大多数 3D 场景 |
| 正交相机 | OrthographicCamera | 大小不变，无透视效果 | 2D UI、地图、工程图 |
| 立体相机 | StereoCamera | 双目视角，产生 3D 效果 | VR、3D 电影 |

### 透视相机 (PerspectiveCamera)

```javascript
// PerspectiveCamera(fov, aspect, near, far)
const camera = new THREE.PerspectiveCamera(
    75,                                      // FOV：视野角度（度数）
    window.innerWidth / window.innerHeight,  // aspect：宽高比
    0.1,                                     // near：近裁面
    1000                                     // far：远裁面
);

// 相机位置
camera.position.set(0, 0, 5);

// 相机朝向（默认看向原点）
camera.lookAt(0, 0, 0);

// 相机视野范围计算
const fovInDegrees = camera.fov;
const aspectRatio = camera.aspect;
const nearPlane = camera.near;
const farPlane = camera.far;

// 根据距离计算视野宽度
function getFovWidthAtDistance(distance) {
    const height = 2 * Math.tan((camera.fov * Math.PI / 180) / 2) * distance;
    const width = height * camera.aspect;
    return { width, height };
}
```

### 正交相机 (OrthographicCamera)

```javascript
// OrthographicCamera(left, right, top, bottom, near, far)
const frustumSize = 10;
const aspect = window.innerWidth / window.innerHeight;
const camera = new THREE.OrthographicCamera(
    -frustumSize * aspect / 2,   // left
    frustumSize * aspect / 2,    // right
    frustumSize / 2,             // top
    -frustumSize / 2,            // bottom
    0.1,                         // near
    1000                         // far
);

// 正交相机不需要设置 FOV，使用 frustumSize 控制视野大小
```

### 相机变换操作

```javascript
// 位置设置
camera.position.set(0, 5, 10);      // 设置位置
camera.position.x = 0;              // 单独设置某轴
camera.position.copy(new THREE.Vector3(0, 5, 10));  // 复制位置

// 朝向控制
camera.lookAt(0, 0, 0);             // 看向某点
camera.lookAt(vector3);             // 看向某向量
camera.lookAt(mesh.position);        // 看向某物体

// 旋转（四元数，避免万向锁）
camera.quaternion.setFromEuler(new THREE.Euler(Math.PI / 2, 0, 0));

// 向上向量（决定相机"头顶"朝向）
camera.up.set(0, 1, 0);  // 默认 Y 轴向上
```

### 相机投影矩阵

```javascript
// 手动更新投影矩阵（在修改相机参数后需要调用）
camera.updateProjectionMatrix();

// 获取投影矩阵
const projectionMatrix = camera.projectionMatrix;

// 获取逆投影矩阵（世界坐标转屏幕坐标时用到）
const inverseProjectionMatrix = camera.projectionMatrixInverse;
```

### 屏幕坐标与世界坐标转换

```javascript
// 世界坐标 → 屏幕坐标
const vector = new THREE.Vector3(0, 0, 0);
vector.project(camera);  // 投影到相机坐标系

// 转换到屏幕像素坐标
const x = (vector.x + 1) / 2 * window.innerWidth;
const y = (-vector.y + 1) / 2 * window.innerHeight;

// 屏幕坐标 → 世界坐标
const mouse = new THREE.Vector2();
mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;

const raycaster = new THREE.Raycaster();
raycaster.setFromCamera(mouse, camera);

const plane = new THREE.Plane(new THREE.Vector3(0, 0, 1), 0);
const target = new THREE.Vector3();
raycaster.ray.intersectPlane(plane, target);
```

## 渲染器 (Renderer)

### WebGL 渲染器

```javascript
// 创建渲染器
const renderer = new THREE.WebGLRenderer({
    antialias: true,           // 抗锯齿
    alpha: true,              // 透明背景
    powerPreference: 'high-performance',  // GPU 偏好
    stencil: true,             // 模板缓冲
    depth: true                // 深度缓冲
});

// 设置渲染尺寸
renderer.setSize(window.innerWidth, window.innerHeight);

// 设置像素比（适配高分屏）
renderer.setPixelRatio(window.devicePixelRatio);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));  // 限制最大 2 倍

// 添加到 DOM
document.body.appendChild(renderer.domElement);

// 执行渲染
renderer.render(scene, camera);
```

### 渲染器输出编码

```javascript
// 控制颜色输出格式
renderer.outputColorSpace = THREE.SRGBColorSpace;    // 标准色彩空间
renderer.outputColorSpace = THREE.LinearSRGBColorSpace;  // 线性色彩空间

// 色调映射（影响最终输出亮度）
renderer.toneMapping = THREE.ACESFilmicToneMapping;
renderer.toneMappingExposure = 1.0;  // 曝光度
```

### 阴影配置

```javascript
// 开启阴影渲染
renderer.shadowMap.enabled = true;

// 阴影贴图类型
renderer.shadowMap.type = THREE.PCFSoftShadowMap;    // 柔和阴影（推荐）
// renderer.shadowMap.type = THREE.BasicShadowMap;  // 基础阴影
// renderer.shadowMap.type = THREE.VSMShadowMap;     // 变体阴影

// 阴影贴图分辨率
renderer.shadowMap.width = 2048;
renderer.shadowMap.height = 2048;
```

### 渲染器状态

```javascript
// 获取渲染器信息（用于调试性能）
console.log(renderer.info);

// 输出示例
// {
//     geometries: 42,
//     textures: 8,
//     programs: 3,
//     triangles: 12500,
//     calls: 1500,
//     points: 0,
//     lines: 500
// }

// 清空渲染目标
renderer.clear();              // 清空颜色、深度、模板缓冲
renderer.clearColor();          // 只清空颜色
renderer.clearDepth();         // 只清空深度
renderer.clearStencil();       // 只清空模板

// 设置清除颜色
renderer.setClearColor(0x000000, 1);  // 黑色，完全不透明
```

### 渲染到纹理（Render Target）

```javascript
// 创建渲染目标
const renderTarget = new THREE.WebGLRenderTarget(
    window.innerWidth,   // 宽度
    window.innerHeight,   // 高度
    {
        minFilter: THREE.LinearFilter,
        magFilter: THREE.LinearFilter,
        format: THREE.RGBAFormat
    }
);

// 渲染到纹理
renderer.setRenderTarget(renderTarget);
renderer.render(scene, camera);

// 获取纹理贴图
const texture = renderTarget.texture;

// 使用后销毁
renderTarget.dispose();
```

### 后期处理集成

```javascript
import { EffectComposer } from 'three/addons/postprocessing/EffectComposer.js';
import { RenderPass } from 'three/addons/postprocessing/RenderPass.js';
import { UnrealBloomPass } from 'three/addons/postprocessing/UnrealBloomPass.js';

// 创建后期处理合成器
const composer = new EffectComposer(renderer);

// 添加渲染通道
const renderPass = new RenderPass(scene, camera);
composer.addPass(renderPass);

// 添加泛光（Bloom）效果
const bloomPass = new UnrealBloomPass(
    new THREE.Vector2(window.innerWidth, window.innerHeight),
    1.5,    // 强度
    0.4,    // 半径
    0.85    // 阈值
);
composer.addPass(bloomPass);

// 在动画循环中使用 composer
function animate() {
    requestAnimationFrame(animate);
    composer.render();
}
```

## 综合示例

### 完整初始化代码

```javascript
// 场景
const scene = new THREE.Scene();
scene.background = new THREE.Color(0x1a1a2e);
scene.fog = new THREE.Fog(0x1a1a2e, 10, 100);

// 相机
const camera = new THREE.PerspectiveCamera(
    75,
    window.innerWidth / window.innerHeight,
    0.1,
    1000
);
camera.position.set(0, 5, 10);
camera.lookAt(0, 0, 0);

// 渲染器
const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
renderer.shadowMap.enabled = true;
renderer.shadowMap.type = THREE.PCFSoftShadowMap;
renderer.outputColorSpace = THREE.SRGBColorSpace;
document.body.appendChild(renderer.domElement);

// 窗口大小变化处理
window.addEventListener('resize', () => {
    // 更新相机宽高比
    camera.aspect = window.innerWidth / window.innerHeight;
    camera.updateProjectionMatrix();
    
    // 更新渲染器尺寸
    renderer.setSize(window.innerWidth, window.innerHeight);
    
    // 如果使用后期处理，也要更新
    composer.setSize(window.innerWidth, window.innerHeight);
});

// 动画循环
function animate() {
    requestAnimationFrame(animate);
    
    // 更新控制器（如果使用 OrbitControls）
    controls.update();
    
    // 渲染场景
    renderer.render(scene, camera);
    
    // 如果使用后期处理
    composer.render();
}

animate();
```

## 性能优化技巧

### 1. 限制像素比

```javascript
// 不要盲目使用最大像素比
renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
```

### 2. 使用实例化渲染

```javascript
// 当有多个相同几何体时，使用 InstancedMesh
const count = 1000;
const instancedMesh = new THREE.InstancedMesh(geometry, material, count);

const matrix = new THREE.Matrix4();
const color = new THREE.Color();

for (let i = 0; i < count; i++) {
    matrix.setPosition(
        Math.random() * 20 - 10,
        Math.random() * 10,
        Math.random() * 20 - 10
    );
    instancedMesh.setMatrixAt(i, matrix);
    
    color.setHSL(Math.random(), 1, 0.5);
    instancedMesh.setColorAt(i, color);
}

instancedMesh.instanceMatrix.needsUpdate = true;
scene.add(instancedMesh);
```

### 3. 视锥体剔除

```javascript
// Three.js 默认启用视锥体剔除，但可以手动控制
mesh.frustumCulled = true;  // 启用
// mesh.frustumCulled = false;  // 禁用（不推荐，除非有bug）
```

### 4. 共享几何体和材质

```javascript
// ❌ 错误：每个物体创建新的几何体和材质
for (let i = 0; i < 100; i++) {
    const mesh = new THREE.Mesh(
        new THREE.BoxGeometry(1, 1, 1),  // 重复创建
        new THREE.MeshBasicMaterial({ color: 0xff0000 })  // 重复创建
    );
}

// ✅ 正确：共享几何体和材质
const sharedGeometry = new THREE.BoxGeometry(1, 1, 1);
const sharedMaterial = new THREE.MeshBasicMaterial({ color: 0xff0000 });

for (let i = 0; i < 100; i++) {
    const mesh = new THREE.Mesh(sharedGeometry, sharedMaterial);
}
```

### 5. 适当的分段数

```javascript
// ❌ 过度细分
const sphere = new THREE.SphereGeometry(1, 128, 128);  // 面数太多

// ✅ 合理细分（根据屏幕大小和距离调整）
const sphere = new THREE.SphereGeometry(1, 32, 24);  // 足够平滑
```

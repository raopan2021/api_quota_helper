## 坐标系详解

### Three.js 坐标系

Three.js 使用右手坐标系（Right-Hand System）：

```
            Y (up)
            ↑
            │
            │________ X (right)
           ╱
          ╱
         ↙ Z (out of screen)
        
    右手握住 Y 轴，大拇指指向 Y 正方向，
    四指弯曲方向为 X→Z 的旋转方向（逆时针）
```

### 位置表示 (position)

每个 3D 物体都有 `position` 属性，是一个 `Vector3` 对象：

```javascript
const cube = new THREE.Mesh(geometry, material);

// 三种等效写法
cube.position.set(1, 2, 3);           // 方式1：直接设置
cube.position.x = 1;                  // 方式2：单独设置各轴
cube.position.y = 2;
cube.position.z = 3;
cube.position.set(1, 2, 3);           // 方式3：链式调用
```

### 旋转表示 (rotation)

旋转使用弧度制（360° = 2π 弧度）：

```javascript
// 绕 X 轴旋转 45 度
cube.rotation.x = Math.PI / 4;  // 45° = π/4 弧度

// 绕 Y 轴旋转 90 度
cube.rotation.y = Math.PI / 2;

// 欧拉角顺序：XYZ（默认顺序）
cube.rotation.set(Math.PI / 4, Math.PI / 2, 0);
```

### 弧度与角度转换

```javascript
// 角度 → 弧度
const radians = degrees * (Math.PI / 180);

// 弧度 → 角度
const degrees = radians * (180 / Math.PI);

// 常用值
const PI = Math.PI;
const HALF_PI = Math.PI / 2;      // 90°
const QUARTER_PI = Math.PI / 4;   // 45°
const TWO_PI = Math.PI * 2;       // 360°
```

### 缩放表示 (scale)

```javascript
// 均匀缩放
cube.scale.set(2, 2, 2);  // 放大2倍

// 非均匀缩放（可产生特殊效果）
cube.scale.set(1, 2, 1);  // Y轴方向拉伸2倍

// 恢复原始大小
cube.scale.set(1, 1, 1);
```

### 变换矩阵 (matrix)

Three.js 会自动计算模型矩阵（Model Matrix），包含位置、旋转、缩放信息：

```javascript
// 获取当前模型矩阵
console.log(cube.matrix);

// 手动更新矩阵（通常自动处理）
cube.updateMatrix();

// 强制从矩阵更新变换
cube.matrixAutoUpdate = false;
```

## 向量基础

### Vector3 基本操作

```javascript
const v1 = new THREE.Vector3(1, 0, 0);
const v2 = new THREE.Vector3(0, 1, 0);

// 加法
const v3 = v1.clone().add(v2);  // (1, 1, 0)

// 减法
const v4 = v1.clone().sub(v2);  // (1, -1, 0)

// 点乘（Dot Product）- 返回标量
const dot = v1.dot(v2);  // 0（垂直向量点乘为0）

// 叉乘（Cross Product）- 返回垂直于两向量的新向量
const cross = v1.clone().cross(v2);  // (0, 0, 1)

// 长度（模）
const length = v1.length();  // 1

// 归一化（单位向量）
const normalized = v1.clone().normalize();  // (1, 0, 0)

// 距离
const distance = v1.distanceTo(v2);  // √2 ≈ 1.414

// 线性插值（Linear Interpolation）
const lerp = v1.clone().lerp(v2, 0.5);  // (0.5, 0.5, 0)
```

### Vector2 二维向量

主要用于 2D 操作，如 UV 坐标、屏幕坐标等：

```javascript
const uv = new THREE.Vector2(0.5, 0.5);  // 中心点
const screenPos = new THREE.Vector2(window.innerWidth / 2, window.innerHeight / 2);

// Vector2 也有 add, sub, dot, normalize, lerp 等方法
uv.normalize();
uv.lerp(new THREE.Vector2(1, 1), 0.3);
```

## 常用几何体

### 1. 立方体 (BoxGeometry)

```javascript
// BoxGeometry(width, height, depth, widthSegments, heightSegments, depthSegments)
const box = new THREE.BoxGeometry(2, 2, 2);                    // 2×2×2 立方体
const boxThin = new THREE.BoxGeometry(2, 1, 0.5);               // 扁平长方体
const boxSegments = new THREE.BoxGeometry(2, 2, 2, 4, 4, 4);    // 带分段（用于细分）
```

### 2. 球体 (SphereGeometry)

```javascript
// SphereGeometry(radius, widthSegments, heightSegments, phiStart, phiLength, thetaStart, thetaLength)
const sphere = new THREE.SphereGeometry(1, 32, 32);              // 光滑球体
const sphereLow = new THREE.SphereGeometry(1, 8, 6);             // 低多边形球体
const sphereHalf = new THREE.SphereGeometry(1, 32, 16, 0, Math.PI);  // 半球
```

### 3. 平面 (PlaneGeometry)

```javascript
// PlaneGeometry(width, height, widthSegments, heightSegments)
// 注意：平面默认在 XZ 平面（竖着的），需要旋转使其水平
const plane = new THREE.PlaneGeometry(10, 10);
plane.rotateX(-Math.PI / 2);  // 旋转成水平地面
```

### 4. 圆形 (CircleGeometry)

```javascript
// CircleGeometry(radius, segments, thetaStart, thetaLength)
const circle = new THREE.CircleGeometry(1, 32);              // 完整圆
const semicircle = new THREE.CircleGeometry(1, 32, 0, Math.PI);  // 半圆
const arc = new THREE.CircleGeometry(1, 32, 0, Math.PI / 2);     // 圆弧（1/4圆）
```

### 5. 圆柱体 (CylinderGeometry)

```javascript
// CylinderGeometry(radiusTop, radiusBottom, height, radialSegments, heightSegments, openEnded)
const cylinder = new THREE.CylinderGeometry(1, 1, 2, 32);       // 标准圆柱
const cone = new THREE.CylinderGeometry(0, 1, 2, 32);           // 圆锥
const tube = new THREE.CylinderGeometry(0.5, 0.5, 2, 32, 1, true);  // 圆筒（无上下底）
```

### 6. 圆环 (TorusGeometry)

```javascript
// TorusGeometry(radius, tube, radialSegments, tubularSegments, arc)
const torus = new THREE.TorusGeometry(1, 0.3, 16, 100);  // 圆环（救生圈形状）
const torusFull = new THREE.TorusGeometry(1, 0.3, 16, 100, Math.PI * 2);  // 完整圆环
const torusPartial = new THREE.TorusGeometry(1, 0.3, 16, 100, Math.PI);  // 半圆环
```

### 7. 圆环结 (TorusKnotGeometry)

```javascript
// TorusKnotGeometry(radius, tube, tubularSegments, radialSegments, p, q)
const torusKnot = new THREE.TorusKnotGeometry(0.8, 0.3, 64, 8, 2, 3);
```

### 8. 十二面体 (DodecahedronGeometry)

```javascript
// DodecahedronGeometry(radius, detail)
const dodecahedron = new THREE.DodecahedronGeometry(1, 0);

// 其他多面体
const tetrahedron = new THREE.TetrahedronGeometry(1, 0);    // 四面体
const icosahedron = new THREE.IcosahedronGeometry(1, 0);  // 二十面体
const octahedron = new THREE.OctahedronGeometry(1, 0);      // 八面体
```

### 9. 文字 (TextGeometry)

需要加载 FontLoader 和字体文件：

```javascript
import { FontLoader } from 'three/addons/loaders/FontLoader.js';
import { TextGeometry } from 'three/addons/geometries/TextGeometry.js';

const loader = new FontLoader();
loader.load('fonts/helvetiker_bold.typeface.json', (font) => {
    const textGeo = new TextGeometry('Hello Three.js', {
        font: font,
        size: 1,
        height: 0.2,
        curveSegments: 12,
        bevelEnabled: true,
        bevelThickness: 0.02,
        bevelSize: 0.05,
        bevelSegments: 5
    });
    const textMesh = new THREE.Mesh(textGeo, material);
    scene.add(textMesh);
});
```

### 10. 组合几何体

使用 `BufferGeometryUtils` 合并多个几何体：

```javascript
import { mergeGeometries } from 'three/addons/utils/BufferGeometryUtils.js';

const geo1 = new THREE.BoxGeometry(1, 1, 1);
const geo2 = new THREE.SphereGeometry(0.5, 16, 16);

// 合并两个几何体
const mergedGeo = mergeGeometries([geo1, geo2]);
const mergedMesh = new THREE.Mesh(mergedGeo, material);
```

## 几何体属性与方法

### 常用属性

```javascript
const geometry = new THREE.BoxGeometry(2, 2, 2);

// 顶点位置
console.log(geometry.attributes.position);  // BufferAttribute

// 顶点法线
console.log(geometry.attributes.normal);

// UV坐标
console.log(geometry.attributes.uv);

// 索引（用于减少顶点重复）
console.log(geometry.index);

// 边界信息
console.log(geometry.boundingBox);   // Box3 包围盒
console.log(geometry.boundingSphere);  // Sphere 包围球
```

### 常用方法

```javascript
// 计算包围盒
geometry.computeBoundingBox();

// 计算包围球
geometry.computeBoundingSphere();

// 中心化（将几何体中心移到原点）
geometry.center();

// 翻转面（法线向外变向内）
geometry.flipNormals();

// 旋转（绕轴旋转几何体本身）
geometry.rotateX(Math.PI / 2);

// 平移
geometry.translate(1, 0, 0);

// 缩放
geometry.scale(2, 1, 1);
```

### 手动创建几何体

使用 `BufferGeometry` 从零创建：

```javascript
// 创建自定义三角形
const geometry = new THREE.BufferGeometry();

// 定义顶点坐标（三个顶点组成一个三角形）
const vertices = new Float32Array([
    0, 1, 0,    // 顶点1
    -1, -1, 0,  // 顶点2
    1, -1, 0    // 顶点3
]);

// 设置顶点属性
geometry.setAttribute('position', new THREE.BufferAttribute(vertices, 3));

// 创建法线（光照必需）
const normals = new Float32Array([
    0, 0, 1,  // 顶点1法线
    0, 0, 1,  // 顶点2法线
    0, 0, 1   // 顶点3法线
]);
geometry.setAttribute('normal', new THREE.BufferAttribute(normals, 3));

// 可选：设置索引（减少顶点重复）
geometry.setIndex([0, 1, 2]);

// 创建网格
const material = new THREE.MeshBasicMaterial({ color: 0x00ff00 });
const mesh = new THREE.Mesh(geometry, material);
scene.add(mesh);
```

## 实践练习

### 练习1：创建复杂场景

```javascript
// 创建一个包含多种几何体的场景
function createScene() {
    const group = new THREE.Group();  // 创建组来管理多个物体
    
    // 地面（扁平立方体）
    const ground = new THREE.Mesh(
        new THREE.BoxGeometry(20, 0.5, 20),
        new THREE.MeshStandardMaterial({ color: 0x228833 })
    );
    ground.position.y = -0.25;
    group.add(ground);
    
    // 球体
    const sphere = new THREE.Mesh(
        new THREE.SphereGeometry(1, 32, 32),
        new THREE.MeshStandardMaterial({ color: 0xff4444 })
    );
    sphere.position.set(-3, 1, 0);
    group.add(sphere);
    
    // 圆环
    const torus = new THREE.Mesh(
        new THREE.TorusGeometry(1, 0.3, 16, 100),
        new THREE.MeshStandardMaterial({ color: 0x4444ff })
    );
    torus.position.set(3, 1, 0);
    group.add(torus);
    
    // 圆柱体
    const cylinder = new THREE.Mesh(
        new THREE.CylinderGeometry(0.5, 0.5, 2, 32),
        new THREE.MeshStandardMaterial({ color: 0xffff44 })
    );
    cylinder.position.set(0, 1, 3);
    group.add(cylinder);
    
    scene.add(group);
    return group;
}
```

### 练习2：鼠标悬停高亮效果

```javascript
import { Raycaster } from 'three';

const raycaster = new Raycaster();
const mouse = new THREE.Vector2();

window.addEventListener('mousemove', (event) => {
    // 将鼠标坐标标准化到 -1 ~ 1 范围
    mouse.x = (event.clientX / window.innerWidth) * 2 - 1;
    mouse.y = -(event.clientY / window.innerHeight) * 2 + 1;
    
    // 发射射线检测
    raycaster.setFromCamera(mouse, camera);
    const intersects = raycaster.intersectObjects(scene.children);
    
    // 重置所有物体颜色
    scene.children.forEach(child => {
        if (child instanceof THREE.Mesh && child.userData.originalColor) {
            child.material.color.copy(child.userData.originalColor);
        }
    });
    
    // 高亮悬停的物体
    if (intersects.length > 0) {
        const mesh = intersects[0].object;
        if (mesh instanceof THREE.Mesh) {
            // 保存原始颜色
            if (!mesh.userData.originalColor) {
                mesh.userData.originalColor = mesh.material.color.clone();
            }
            // 设置高亮色
            mesh.material.color.setHex(0xffff00);
        }
    }
});
```

### 练习3：实现缩放动画

```javascript
function createScalingAnimation(mesh) {
    let scale = 1;
    let growing = true;
    
    function animate() {
        // 呼吸效果：1.0 ~ 1.3 之间缩放
        if (growing) {
            scale += 0.002;
            if (scale >= 1.3) growing = false;
        } else {
            scale -= 0.002;
            if (scale <= 1.0) growing = true;
        }
        
        mesh.scale.set(scale, scale, scale);
        requestAnimationFrame(animate);
    }
    
    animate();
}
```
